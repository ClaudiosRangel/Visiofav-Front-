# VisioFab WMS - Frontend

Next.js 15 + Mantine 7 + TanStack + TypeScript.

## Setup

```bash
# 1. Instalar dependências
npm install

# 2. Rodar em dev
npm run dev
```

Aplicação disponível em `http://localhost:3000`
